# 轻账 · 心中有数

面向 iPhone 的离线记账 PWA，人民币单币种，HTML / CSS / JavaScript + IndexedDB。无广告、无追踪、无服务端账单存储。

## 已实现

- 收入、支出、账户间转账；账单修改与删除。
- 多账户、初始余额、资产负债和净资产，转账不计入收支。
- 分类新增、重命名与安全删除；账单按月、类型、账户和关键词筛选。
- 月度总预算、分类预算及超支显示。
- 月度/年度统计、六个月趋势、分类占比、日均支出、结余率和规则式消费分析。
- 每日/每周/每月周期计划，到期后手动确认入账；避免重复确认。
- JSON 完整备份与恢复；可选 AES-256-GCM 加密，PBKDF2-SHA256 250000 次密钥派生。密码无法找回。
- CSV 全量明细导出，处理单元格公式注入。
- 本地演示账本，与真实账本隔离。
- PWA 图标、独立窗口、生产版 Service Worker 离线资源缓存、版本更新提示。
- iPhone 安全区、动态视口、键盘高度、触摸操作、焦点限制和减少动画偏好。

## iPhone 使用

1. 用 Safari 打开固定 HTTPS 网址，首次等待页面加载完成。
2. 轻点分享 → 添加到主屏幕 → 添加。
3. 从主屏幕打开，进入“账户”填写开始记账前的余额，欠款填写负数。
4. 轻点底部“记一笔”开始记录。
5. 设置 → 备份与恢复 → 生成备份文件 → 分享 / 存储到文件 → iCloud 云盘。
6. 在“文件”App 中进入 iCloud 云盘的“轻账”文件夹，保存为默认的 `轻账-最新备份.json`；如果提示同名文件，选择“替换”。每周及重大修改后备份一次。

iCloud 云盘功能是**用户手动保存文件**，不是自动云同步。设置中的“固定备份文件名”默认开启，方便在同一目录替换上一份；网页无法在后台任意写入个人 iCloud 云盘、删除旧文件或直接选择指定目录。分享与下载是两种独立的保存方式，每次只需选择一种。当前版本不依赖 Apple Developer 账号。

首次安装后，建议开飞行模式重新打开并记一笔测试账单，验证设备上的离线缓存。再联网导出、恢复一次备份确认完整流程。

## 数据边界

- 数据属于当前网址的浏览器存储；换域名、清理网站数据、系统回收存储或换设备都可能失去本地数据。必须另存备份。
- 从 Safari 和主屏幕不同入口打开可能有不同的存储环境，请固定使用主屏幕入口，迁移时通过备份恢复。
- 导出时间只表示发起下载或完成分享，不能证明文件已在 iCloud 上传成功。
- 加密仅保护导出的备份。本地数据库不是应用层加密数据库，请用设备密码保护手机。
- 恢复会完整替换当前账本；导入前校验金额、日期、关联账户和分类。建议先导出原账本。
- 周期账单需要打开应用并确认，不包含后台推送通知、银行接口、自动抓取支付记录、票据 OCR 或自动 iCloud 同步。
- 当前支持人民币，无多币种换算。统计分析为可解释的本地规则；可选的 AI 截图识别只处理本次截图文字。
- 月末周期计划会取目标月份最后一天，并从调整后的日期继续。
- 日均支出：当月按截至今天的天数，历史月份按整月，年度按全年天数。

## 开发与测试

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install webkit chromium
npx playwright test
```

生产文件在 `dist/`，部署整个目录到 HTTPS 静态托管即可。不需服务器数据库。不要通过直接打开 `index.html` 使用应用。

`public/sw.js` 仅用于开发，生产 Service Worker 在构建时生成，并预缓存精确的构建资源。资源无 CDN、远程字体等运行时依赖。

金额使用整数分进行计算。数据库更新在单个 IndexedDB 读写事务中读取最新状态并写入，避免多个标签页造成覆盖。BroadcastChannel 用于同步刷新页面。

## 验证范围

自动化涵盖金额精度、转账与余额、日期边界、备份校验、加密往返、错误密码、CSV 安全，以及 WebKit/Chromium 的账单增改删、账户、预算、周期账单、导入恢复和移动端溢出检查。

WebKit 测试模拟移动端浏览器，不等同于实体 iPhone 验收。真实设备上的安全区、键盘、添加到主屏幕及 iCloud 分享文件仍需实际确认。


## 截图记账（微信 / 支付宝）

设置 → 截图记账快捷指令会提供已签名的 iPhone 快捷指令文件。快捷指令在设备本地截取当前屏幕、提取文字、复制到剪贴板并提示返回轻账；轻账再解析实付/实收金额、平台、商户、收支方向、分类和日期，必须确认后才写入本地账本。未开启 AI 时，识别文本不会上传；开启后会发送本次文字及分类列表到 DeepSeek。剪贴板设置为仅本地。

快捷指令不能直接写入网页的 IndexedDB；为避免打开 Safari 产生另一份账本，快捷指令复制结果后通过 webapp:// 尝试唤起原来的主屏幕轻账。受保护付款页面可能不能截屏，识别只是建议，优惠、余额、退款和转账请人工核对。


### 点击截图记账即读取

运行正式“轻账截图识别”指令后，点击网页“截图记账”会立即在同一次用户点击中请求剪贴板。允许系统粘贴后直接进入确认页，无需再点“粘贴并识别”。启动/后台恢复不读取，保存后不再次读写剪贴板；摘要去重保留。拒绝/空内容时提供重试和手动粘贴。URL 测试入口及自动读取开关已移除，旧快捷指令无需更新。

截图记账也可从四个主页面右下角的浮动按钮打开；可拖动并记住设备上的位置。打开弹窗时隐藏。

分类选择、分类管理、预算和周期账单按本地全部账单的使用次数排序，同频保持原顺序。补充常见分类及图标，已有分类 ID 和账单归属保持不变；补全仅执行一次，之后删除的分类不会在重启时恢复。统计页仍按金额展示占比。

记账分类默认两行五列，分类超过十项时显示九个常用分类及展开按钮；展开后可收起，隐藏的已选分类会在标题提示，表单内容保持不变。


## 可选 DeepSeek 截图识别

设置 → AI 截图识别 → 填写自己的 API Key → 保存并测试连接。使用 `deepseek-flash`，`thinking: disabled`，JSON 输出，上限 500 输出 tokens。现有快捷指令不变。金额、日期、收支与账户仍使用原有本地解析和确认；模型只建议分类、提取商家与商品生成备注。分类每次来自当前用户分类目录，删除或不匹配的分类不会创建关联。

设备直接请求 `https://api.deepseek.com/chat/completions`，不经应用代理。仅发送本次 OCR 文字（尽量移除订单号、卡号等号码，但不是完全匿名化）和对应收支方向的分类 ID/名称，不发送历史账本、账户列表或图片。默认不启用，启用及连接测试会消耗用户的 DeepSeek API 余额。测试只发送虚构面馆账单。

密钥放在设备 localStorage 的独立配置 `qingzhang.deepseek.v1`，不放入账本 state、JSON/CSV 备份、构建代码或 GitHub。localStorage 不是系统钥匙串或应用层加密保险库；同源脚本可访问，请仅使用可信站点和设备。清理网站数据、更换设备或入口后需重新填写。可切回仅本地或移除密钥。

20 秒超时、断网、无效密钥、余额不足、限流及异常 JSON 都会回到本地识别，并在确认页说明原因；不自动重试收费请求。等待时可直接使用本地结果，关闭弹窗会取消等待。请求前检查重复账单；只有点击保存才入账。API 返回值经过字段与分类校验、备注来源检查和 HTML 转义，不接受模型修改金额或执行动作。

接口依据：[模型列表](https://api-docs.deepseek.com/quick_start/pricing)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode)，核对日期 2026-11-03。
